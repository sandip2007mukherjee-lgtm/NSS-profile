NSS Poster Studio Pro
========================
1. Upload all files to a GitHub repository.
2. Open index.html through GitHub Pages.
3. Choose member count (1–10).
4. Fill group, quote, leader and member information.
5. Upload photos.
6. Download PNG/JPG/PDF or save a draft in the same browser.

The supplied master poster is included as master-reference.jpg.
The app is intentionally built around the same A4 visual structure: NSS logos, Kalam header, quote, leader card, member cards and blue footer.
